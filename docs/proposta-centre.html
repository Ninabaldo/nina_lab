01

Una experiència per a cada perfil

App per als alumnes

Una manera senzilla de consultar les classes i gestionar les reserves des del mòbil.

Funcionalitats bàsiques del mockup:

  • Horaris: consulta les activitats programades i les places disponibles.
  • Reserves: reserva una classe o cancel·la una plaça.
  • Les meves classes: consulta les pròximes reserves i l'historial.
  • Abonaments: visualitza el teu pack o membresia i les classes disponibles.
  • Perfil: consulta les teves dades i preferències.

Dashboard per al centre

Un espai de gestió per tenir les classes, els alumnes i les reserves organitzades en un mateix lloc.

Funcionalitats bàsiques del mockup:

  • Resum: cobraments, indicadors clau, ocupació i classes del dia.
  • Calendari: organitza les activitats per dies i hores.
  • Classes: alumnes per classe, aforament i horaris per activitat.
  • Alumnes: base de dades amb cerca, plans i activitat recent.
  • Abonaments: gestiona els packs i les membresies del centre.

Això és només un exemple interactiu. La plataforma es pot configurar segons les necessitats del centre i activant només els components que es vulguin.

05

Com continuem?

Abans de començar el desenvolupament, farem una sessió de definició per concretar les necessitats del centre i validar l’abast del projecte.

  • Revisarem les funcionalitats seleccionades i les prioritats del centre.
  • Definirem els processos de reserva, cancel·lació i gestió de classes.
  • Validarem les pantalles i l’experiència dels alumnes i de l’equip del centre.
  • Concretarem les integracions necessàries, els terminis i les condicions de pagament.

Una vegada validada aquesta informació, prepararem el pressupost definitiu i el calendari de desenvolupament.

El projecte començarà un cop aprovada la proposta definitiva i acordades les condicions d’inici.
