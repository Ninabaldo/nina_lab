Proposta de software

El teu centre, amb el seu propi sistema.

Una plataforma de gestió de classes dissenyada per adaptar-se al funcionament del teu centre.

Consulta la proposta, explora les dues experiències de software i configura les funcionalitats que necessites. Els imports de Nina Lab no inclouen subscripcions ni comissions de tercers (domini, hosting, pagaments…).

01

Una experiència per a cada perfil

App per als alumnes

Una manera senzilla de consultar les classes i gestionar les reserves des del mòbil.

Funcionalitats bàsiques del mockup:

  • Horaris: consulta les activitats programades i les places disponibles.
  • Reserves: reserva una classe o cancel·la una plaça.
  • Les meves classes: consulta les pròximes reserves i l'historial.
  • Abonaments: visualitza el teu pack o membresia i les classes disponibles.
  • Perfil: consulta les teves dades i preferències.

Dashboard per al centre

Un espai de gestió per tenir les classes, els alumnes i les reserves organitzades en un mateix lloc.

Funcionalitats bàsiques del mockup:

  • Resum: cobraments, indicadors clau, ocupació i classes del dia.
  • Calendari: organitza les activitats per dies i hores.
  • Classes: alumnes per classe, aforament i horaris per activitat.
  • Personal (coaches): gestiona l’equip, assignacions a classes i disponibilitat dels coaches.
  • Alumnes: base de dades amb cerca, plans i activitat recent.
  • Abonaments: gestiona els packs i les membresies del centre.

Això és només un exemple interactiu. La plataforma es pot configurar segons les necessitats del centre i activant només els components que es vulguin.

05

Com continuem?

Abans de començar el desenvolupament, farem una sessió de definició per concretar les necessitats del centre i validar l’abast del projecte.

  • Revisarem les funcionalitats seleccionades i les prioritats del centre.
  • Definirem els processos de reserva, cancel·lació i gestió de classes.
  • Validarem les pantalles i l’experiència dels alumnes i de l’equip del centre.
  • Concretarem les integracions necessàries, els terminis i les condicions de pagament.

Una vegada validada aquesta informació, prepararem el pressupost definitiu i el calendari de desenvolupament.

El projecte començarà un cop aprovada la proposta definitiva i acordades les condicions d’inici.

06

Si deixeu el manteniment o canvieu de desenvolupador

El centre és propietari del software desenvolupat. Tant si opteu per no contractar manteniment com si en el futur voleu treballar amb un altre equip, el projecte ha de quedar operatiu i transferible sense dependre exclusivament de Nina Lab.

  • Sense manteniment: el software continua funcionant; les actualitzacions, incidències i evolucions es poden encarregar internament o amb un altre proveïdor.
  • Canvi de desenvolupador: lliurem el projecte de forma ordenada perquè un nou equip pugui continuar el desenvolupament i el desplegament.

Què lliuraríem

  • Codi font complet en un repositori GitHub del centre (web, backend, apps i scripts de desplegament).
  • Documentació per instal·lar el projecte, executar-lo en local i desplegar-lo a producció.
  • Llista de variables d’entorn i guia de transferència segura de secrets (sense enviar contrasenyes per email).
  • Accés o export de la base de dades, esquema, migracions i procediment de còpies de seguretat.
  • Inventari de comptes externs al nom del centre (domini, hosting, stores, pagaments, email).

Com seria la transferència

  1. Sessió de lliurament amb el centre (i el nou equip, si ja el teniu).
  2. Transferència del repositori GitHub i revisió de permisos d’administració.
  3. Revisió conjunta de desplegament, còpies de seguretat i restauració de la base de dades.
  4. Període breu de suport per dubtes tècnics del lliurament (durada acordada al contracte).

L’objectiu és que el centre no quedi “atrapat”: el producte és vostre i ha de poder evolucionar amb l’equip que trieu.

07

Costos externs (a càrrec del centre)

A banda del pressupost de desenvolupament i, si s’escull, del manteniment mensual amb Nina Lab, el centre haurà de mantenir els comptes i subscripcions dels serveis que fan funcionar la plataforma en producció. Aquests imports es paguen directament als proveïdors, no a Nina Lab.

Les xifres següents són ordres de magnitud orientatius; poden variar segons el proveïdor, el país, l’IVA, el volum d’ús i el pla contractat.

No inclòs com a subscripció, però sí que ho configurem amb les vostres dades

Les quotes dels proveïdors no formen part del preu d’implementació de Nina Lab, però sí que podem deixar-ho connectat i documentat: integració al codi, entorns, desplegament i proves, sempre amb comptes al nom del centre i dades que faciliti el centre (o el seu administrador IT).

  • Repositori GitHub del centre, CI/CD i desplegament inicial a hosting (web i API).
  • Enllaç del domini i HTTPS (registres DNS al registrador del centre).
  • Base de dades gestionada: projecte, esquema inicial, migracions i variables d’entorn (dev / producció).
  • Stripe: connexió al compte del centre, entorns de prova i producció, webhooks i fluxos acordats.
  • Email transaccional: verificació del domini, DNS i plantilles bàsiques si s’inclouen a l’abast.
  • Apps (si s’han contractat): builds i publicació a App Store / Google Play amb comptes de desenvolupador del centre.
  • Altres integracions de l’abast (calendaris, analytics, IA, etc.) amb les claus o invitacions d’admin que proporcioni el centre.

El centre obre els comptes al seu nom i dona accés d’administrador a Nina Lab (invitació GitHub, Stripe, hosting, BD, etc.). No demanem contrasenyes per email; secrets i claus API es configuren com a variables d’entorn i es documenten per a una transferència segura.

Domini i hosting

  • Domini web — Pagament periòdic al registrador (p. ex. anual). Cal per a la URL pública del centre.
  • Hosting web i API — Quota mensual segons trànsit i recursos (p. ex. Vercel o equivalent). Sovint hi ha un pla gratuït limitat; en producció real acostuma a haver-hi cost.
  • HTTPS — Normalment inclòs al hosting en enllaçar el domini.

Base de dades

  • PostgreSQL gestionat (Supabase, Neon, etc.) — Compte al nom del centre. Pla gratuit inicial possible; cost mensual en augmentar dades, connexions o còpies.

Pagaments online

  • Stripe (compte del centre) — Comissió per transacció reeixa (percentatge + import fix). Les descompta Stripe; no les gestiona Nina Lab. Liquidació al compte bancari del centre.

Email i notificacions

  • Email transaccional — Servei tipus Resend, Postmark o SendGrid: quota segons volum (confirmacions, recordatoris). Cal configurar DNS del domini.
  • SMS (opcional) — Cost per missatge si el centre vol recordatoris per SMS.

Apps a stores (si s’inclouen)

  • Apple Developer Program — Aprox. 99 USD/any — compte de desenvolupador al nom del centre.
  • Google Play Console — Aprox. 25 USD (pagament únic) — compte al nom del centre.

Opcional

  • Intel·ligència artificial (API) — Cost per ús si s’integren funcions d’IA; compte i facturació del proveïdor.
  • Altres integracions — Calendaris, analytics, eines de marketing, etc., segons el que s’acordi al projecte.

El manteniment mensual amb Nina Lab (si es contracta) cobreix el software desenvolupat per nosaltres: incidències, actualitzacions tècniques acordades, etc. No substitueix les factures de domini, hosting, base de dades, Stripe, email, stores ni altres serveis de tercers.

Recomanem obrir aquests comptes al nom del centre des del principi i deixar-ne constància al contracte, per evitar sorpreses i facilitar un possible canvi de proveïdor.
